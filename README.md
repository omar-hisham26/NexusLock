## كيف تستخدمه؟
1. قفل لعبة **Overwatch** أول شي.
2. شغل البرنامج `NetherWatch.exe`.
3. اضغط على زر **🛡️ تبليك السيرفرات (سيرفر هولندا بيكون شغال)**.
4. خلاص شغل اللعبة والعب! السيرفرات الثانية كلها مبلكة.
5. تقدر تقفل البرنامج عادي الحظر بيبقى شغال، وإذا تبي تلعب طبيعي افتح البرنامج واضغط **🔓 فك البلوك**.

## تنبيهات على السريع
> [!IMPORTANT]
> - **إذا تلعب مع خويك ببارتي:** لازم هو بعد يبلك السيرفرات بنفس البرنامج، ولا الماتشميكنق بيحذفكم بسيرفر ثاني.
> - **التدريب (Practice Range):** سيرفراته غير، جرب في كستم قيم أو قيم سريع وتأكد.
> - **واللعبة شغالة:** البرنامج بيخفي أزرار التبليك تلقائياً، قفل اللعبة عشان تقدر تبلك أو تفك.

## أسئلة شائعة
- **فيه باند؟**  
  لا نهائياً، ما يحقن ملفات ولا يلمس اللعبة، مجرد قاعدة بجدار حماية ويندوز زي برامج حجب الإعلانات.
- **لازم أخليه شغال بالخلفية؟**  
  لا، التبليك مستمر حتى لو قفلت البرنامج إلا إذا فعلت خيار الفك التلقائي.
- **أبي أرجع جهازي وكالة زي أول؟**  
  اضغط زر **⚙️ ضبط المصنع** وبينظف كل القواعد ويرجع لك الويندوز طبيعي 100%.
