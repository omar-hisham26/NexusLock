## 🚀 طريقة الاستخدام بكل بساطة (بـ 3 خطوات بس)

1. **حمّل وثبّت البرنامج:**
   - اضغط على زر التحميل الأخضر اللي فوق وثبّت البرنامج على جهازك، وشغّله كمسؤول (عشان يقدر يضيف قواعد جدار الحماية).

2. **اختر لعبتك والسيرفر اللي تبيه:**
   - ادخل على اللعبة (أوفرواتش 2 أو ديدلوك)، واختر السيرفر اللي ودك تلعب عليه، وتقدر تفحص بنق السيرفر بضغطة زر وتشوف كم البنق قبل تبدأ.

3. **فعّل التبليك والعب براحتك:**
   - تأكد إن اللعبة مقفلة، واضغط زر **«تثبيت السيرفر»** الأخضر. مبروك! كذا تقفلت كل السيرفرات البعيدة وما راح يدخلك إلا على السيرفر اللي اخترته.
   - إذا خلصت لعب وتبي ترجع كل السيرفرات طبيعية، اضغط زر **«فك الحظر»** الأحمر.

## 🛡️ هل البرنامج يجيب باند؟ (ضمان الأمان)

**تطمن وريّح بالك، آمن 100% وما عليه أي باند نهائياً (Zero-Ban Guarantee):**
* البرنامج **ما يلمس ملفات اللعبة** ولا يعدل عليها ولا يحقن أي كود بالذاكرة (ما فيه أي Memory Injection).
* كل اللي يسويه البرنامج إنه يشتغل من برّا عن طريق **جدار حماية ويندوز الرسمي (Windows Firewall)** عشان يمنع جهازك يتصل بآيبيات السيرفرات البعيدة.
* تقدر تلعب فيه بالرانك والتنافسي وأنت متطمن.

## ✨ ميزات ثانية بتعجبك

* **واجهة حديثة وخفيفة:** سريعة وما تستهلك موارد جهازك ولا تسوي لاق.
* **عربي كامل وإنجليزي كامل:** تقدر تبدل بين العربي والإنجليزي بضغطة زر من القائمة الجانبية والكلام ما يتداخل أبداً.
* **فحص بنق حي ومباشر:** يعطيك البنق التقريبي للسيرفر قبل لا تشبك.
* **تنظيف الشبكة (Flush DNS):** زر ينظف كاش الشبكة ويضبط لك الاتصال لو حسيت فيه تهنيج.
* **ضبط المصنع:** بضغطة زر واحدة يمسح لك كل القواعد ويرجع إعدادات جهازك زي ما كانت أول.
